🔍 Project Overview

What is DiabetesAI?

An end-to-end clinical machine learning system developed during the CodeAlpha internship, moving from raw diagnostic data to a validated 87% accuracy classifier and interactive deployment.

🌲
Random Forest Champion
Evaluated Logistic Regression, Random Forest, and SVM. Random Forest outperformed all models, achieving 87% accuracy with superior generalization on non-linear clinical interactions.
⚗️
Clinical Feature Engineering
Engineered 6 domain-specific features: Glucose×BMI interaction, insulin resistance index, hyperglycemia flag (≥126 mg/dL), obesity indicator, and metabolic load metrics.
💾
Saved Pipeline Architecture
Exported best_model.pkl and scaler.pkl pipelines ensuring strict consistency between training preprocessing and live inference without data leakage.
🎨
Interactive Streamlit App
Developed a dark glassmorphic web dashboard with real-time confidence meters, patient profile quick-filling, and comprehensive clinical range guides.
📋
Stratified Imputation

🔒
Offline & Privacy-First
All inference runs locally via serialized Python artifacts. Zero patient telemetry or external API dependencies ensure complete healthcare confidentiality.

🔄 End-to-End Pipeline

Development Lifecycle

01
Data Acquisition & Exploratory Analysis
Loaded the Pima Indians Diabetes Dataset. Analyzed distributions, skewness, and detected physiologically impossible zero values across blood pressure, glucose, insulin, skin thickness, and BMI.
02
Stratified Imputation & Preprocessing
Imputed zero values with class-stratified medians to preserve distinct clinical distributions. Scaled features using StandardScaler to eliminate magnitude bias.
03
Feature Engineering (+6 Attributes)
Engineered non-linear interaction terms (Glucose×BMI, Insulin ratio) and binary clinical threshold indicators (diabetic fasting blood sugar, obesity classification).
04
Model Comparison & Champion Selection
Trained and compared Logistic Regression (77.3%), SVM (78.6%), and Random Forest (87.0%). Selected Random Forest as the final production model based on superior accuracy.
05
Pipeline Serialization
Saved trained Random Forest model (best_model.pkl) and fitted scaler (scaler.pkl) to ensure identical inference preprocessing with zero data leakage.
06
Streamlit Interactive Deployment
Created an interactive web application with dark-mode glassmorphism styling, real-time prediction confidence meters, quick-fill profiles, and dynamic range status warnings.
